- **`expected` and the parsers are constant-evaluable since C++20 (#430).** A constant expression can create an `expected`, read it through its observers (`has_value`, `operator*`, `operator->`, `value`, `error`, `value_or`, `error_or`) and destroy it. So `try_parse_uint`, `try_parse_int`, `try_parse_hex` and the asserting `parse_*` run at compile time, and a table of text is parsed at build time; a bad entry fails the build. C++17 is unchanged: no destructor can be `constexpr` there.
