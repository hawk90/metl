- `metl::exp::intrusive_forward_list<T, Tag>` (`<metl/exp/intrusive_forward_list.hpp>`): a singly linked list of objects the caller owns, such as static driver descriptors, linked through a `forward_list_hook<Tag>` base without allocating or copying. The hook records the list it is in, so three misuses stop the program at every hardening level: destroying an element while it is linked, linking it while it is already linked, and erasing it through a list it is not in. Storage reused without the element's destructor running cannot be checked and is stated as the contract (#337).
