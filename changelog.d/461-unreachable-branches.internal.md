- Removed five branches no caller can take, which the 1.5.0 coverage records listed as unreachable. `align_up` in `arena_allocator` and `monotonic_buffer` no longer checks for a zero alignment: `METL_HARDEN`, which is on at every hardening level, rejects one first. `bitset`'s last-word mask no longer takes a word index. `try_parse_hex` no longer compares the last digit: the limit of every unsigned type ends in the hex digit F. `variant` assignment no longer checks whether the source lies inside its own storage: an alternative is smaller than the variant, so it cannot contain one (#461).
