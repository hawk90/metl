- Each release attaches `metl-X.Y.Z-measurements.json`: the code, constant, RAM and thread-local storage sizes main's CI measured for the tagged commit on each Cortex-M target, section by section, with the stack figures. A value that was not measured is `null`. The size gate now classifies sections by ELF type and flags, so RAM under a name other than `.bss` or `.data` (thread-local storage, `.noinit`) is counted (#405).
