- `metl::exp::once_flag` and `metl::exp::try_call_once` (Tier 2, `<metl/exp/once_flag.hpp>`): run an initializer once without waiting, and without holding the lock around it. A caller that finds it running in another context, an interrupt that preempted it or the initializer calling itself, gets `false` instead of re-entering it. The state change takes a `Lock` policy, `irq_lock` by default, so it works on ARMv6-M, which has no compare-exchange. It answers the function-local static that an interrupt enters mid-construction, which QEMU shows constructed twice under `-fno-threadsafe-statics` and trapping in `__cxa_guard_acquire` otherwise (#486).
