- `metl::object_pool` takes a slot in constant time from a free list kept in the freed slots' own bytes, and marks live slots with one bit each instead of a byte (#336). A freed slot is now reused before a never-used one, last freed first; the pool used to take the lowest free index. A slot of a `T` smaller than the link (1 byte up to 255 slots, 2 up to 65535) grows to the link's size.
