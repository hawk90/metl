- `metl::handle_pool` keeps neither a per-slot occupancy flag nor a separate free list: a slot's generation is odd while it is live and even while it is free, and a free slot keeps its free-list link in the object's own storage, so a pool is smaller by up to 3 bytes per slot. **Behaviour change:** a slot cycles through half as many generations before they repeat, 32768 instead of 65535 with the default 16-bit counter (#336).
