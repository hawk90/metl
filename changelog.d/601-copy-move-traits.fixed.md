- Every container, `optional`, `expected` and `variant` declares its copy and move operations only when its element (and comparator, hasher or key-equal) allows them, so `std::is_copy_constructible_v`, `std::is_move_constructible_v`, the assignment traits and `std::is_swappable_v` follow the element, as for `std::array` and `std::optional`. They were true for any element, and code that asks them, such as a `std::optional` of a container of non-movable elements, got a hard error instead of `false`. Layout and generated code are unchanged (#601).
