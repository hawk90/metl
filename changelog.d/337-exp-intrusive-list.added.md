- `metl::exp::intrusive_list<T, Tag>` (`<metl/exp/intrusive_list.hpp>`): a doubly linked list of objects the caller owns, linked through a `list_hook<Tag>` base. Any element unlinks in O(1), as a cancelled timer needs, for one pointer more per hook than `intrusive_forward_list`. The same misuses stop the program at every hardening level: destroying an element while it is linked, linking it while it is already linked, erasing it through a list it is not in, and erasing `end()`. The list is constant-initialized, so a static initializer in another translation unit can link into it (#337).
