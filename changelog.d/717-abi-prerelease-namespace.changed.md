- **Breaking (ABI):** a pre-release now opens its own ABI namespace: 2.0.0-alpha.3 puts everything in `metl::v2::alpha3_h<level>_noexc<0|1>_tabi<0|1>`, and a release, 2.0.0 included, will use the name without the `alpha3_` prefix (#717). Code still names `metl::fixed_vector`, so source is unaffected. An object built against one pre-release, such as a prebuilt SDK, now fails to link with an object built against another or against the release, and the undefined symbol names the pre-release. Before, the two linked and ran each other's code, because pre-releases change return types and a return type is not part of a mangled name. alpha.1 and alpha.2 were cut without a prefix, so their names are the release's: rebuild everything built against them.
