- `expected` and `variant` are constant-initialized at namespace scope, in C++17 as well as C++20 (#395). Their default, value, error and in-place constructors were labelled `constexpr` but built the member with placement new, which no constant expression allows, so a global was constructed at run time in link order and `constinit` on one failed to compile. They now build it in a union member initializer. `sizeof` and alignment are unchanged.
