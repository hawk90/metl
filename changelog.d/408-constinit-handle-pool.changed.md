- **`handle_pool` is constant-initialized since C++20 (#408).** An empty pool is all zero bits, so a namespace-scope pool is ready before any dynamic initializer runs, lands in `.bss`, and `constinit` accepts it. Slots are handed out in index order as before, and a freed slot is reused first. `sizeof` is unchanged. In C++17 a namespace-scope pool is still initialized at run time, in link order.
